# A.I. Client Acquisition Super Suite — launch video

Launch promo for Trainor Media Network's **A.I. Client Acquisition Super Suite**, built with [HyperFrames](https://github.com/heygen-com/hyperframes) (HTML + GSAP compositions rendered to MP4).

| Folder | Format | Hook |
|---|---|---|
| `super-suite-promo/` | 16:9 (1920×1080), YouTube / web | A — "Missed calls. A quiet calendar…" |
| `super-suite-promo-hookB/` | 16:9 | B — "Right now, someone near you is searching…" |
| `super-suite-promo-vertical/` | 9:16 (1080×1920), Reels / TikTok | A |
| `super-suite-promo-vertical-hookB/` | 9:16 | B |

Everything after the hook (frames 2–9: the Super Suite reveal, the five systems, the CTA and the brand end card) is identical across all four, so the A/B test isolates the hook.

## Render

```bash
cd super-suite-promo          # or any of the four folders
npm install
npx hyperframes check
npx hyperframes render --quality high --output renders/video.mp4
```

## How the frames are generated

Frame HTML in `compositions/frames/` is generated by `tools/build_frames.py` (16:9) and `tools/build_frames_v.py` (9:16). Set `HOOK=b` to build hook B:

```bash
cd super-suite-promo-hookB && HOOK=b python3 ../tools/build_frames.py .
```

After re-assembling `index.html` with the product-launch-video workflow scripts, run the matching `tools/post_assemble*.sh` to re-apply the local GSAP path, the voiceover audio group, the film-grain overlay and the music carve.

## Audio

Voiceover (voice "Kyle"), music bed and sound effects were generated with ElevenLabs. Word timings come from ElevenLabs Scribe and live in each project's `audio_meta.json`.
