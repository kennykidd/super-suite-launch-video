## Video direction

- **palette system** — frame.md: dark navy canvas (#060B1E) with a faint radial glow + soft grid; white display type, electric blue (#2EA8FF) is the single headline accent; each system owns its `sys-*` icon color (leads blue, receptionist green, reputation purple, social orange, website sky) used only on that system's icon disc + UI accents; purple `cta` only on the Discover pill; `brand-gold` only in the closing lockup. Cards = dark glass (card-bg tint + 1.5px border, 14px radius).
- **motion grammar + reveal model** — power3/expo long-tail eases, smooth over bouncy (one spring-pop allowed per frame for the payoff); every piece reveals on its spoken cue; a slow camera push (scale 1→1.04) runs underneath feature frames; no exits on non-final frames.
- **system-frame template (frames 3–7)** — shared layout so the five read as one series: left column (x≈140–760) = icon disc (128px) + system eyebrow "0N / 05" + title (2 lines, uppercase Space Grotesk 700) + one short benefit chip; right stage (x≈820–1780) = that system's UI mockup on a glass panel. Left column enters first on the system name; the UI performs across the rest.
- **rhythm / held frames** — Frame 2 lands then holds ~1.5s on the full suite ring; Frame 8 pill holds after the click; Frame 9 is the deliberate held end card. Everything else reveals to VO.
- **negative list** — no stock photos, no lens flares, no glitch, no narration sentences as on-screen text; never front-load-then-freeze (slideshow) and never everything drifting independently (screensaver).
